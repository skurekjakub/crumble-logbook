[방어/유틸 부위] 오른쪽 아래
마법물체 : 스가 + 피감
책 : 스가 + 피감
음식 : 스가 + 피감
• 슈가룬 추천 옵션
- 우유맛 쿠키 : 공격력
- 석류 / 마카롱 / 치즈케이크 / 실론비치맛 쿠키 : 스킬 증폭
- 시커맛 쿠키 : 스킬 가속 45~47 맞춘 후, 남는 수치는 스킬 증폭 또는 치명타 피해
(해당 스가 수치가 잡몹 처리 시 드론이 튀는 현상을 방지하는 최적 구간입니다. 종결 SSR 세팅이 완료된 후 마지막 순서로 진행하는 것을 권장하며, 개인 취향에 따라 참고만 해주세요.)
- 피겨쿠키 : 스킬 증폭 + 스킬 가속
(장비 포함 시커의 스가 수치를 고려하여 시커:피겨 스가 비율을 1.41 : 1로 맞추는 세팅입니다.)
* 시커 스가 45 미만 : 피겨 스가 0
* 시커 스가 45 이상 : 피겨 스가 32
* 시커 스가 52 이상 : 피겨 스가 37 이상
- 정글전사 쿠키 : 스킬 가속 8 이상 + (스킬 증폭 / 치명타 피해 / 공격력 중 선택)
(올 스킬 가속 세팅도 유효함)
- 전갈맛 쿠키 : 스킬 가속 / 스킬 증폭 / 치명타 피해 / 공격력 중 선택
(공격력 선택 시 우유맛 쿠키의 공격력을 넘지 않도록 주의. 스가 수치가 너무 높으면 스테이지 무빙 컨트롤이 어려워질 수 있습니다.)
- 피노키키 / 블랙초코 쿠키 : 스킬 가속 위주
(스킬 발동 횟수를 늘려 버프/디버프 중첩 확률을 높이는 전략입니다. 아레나까지 고려한다면 집중이나 피해 감소도 좋은 선택지입니다.)
- 체리맛 쿠키 : 스킬 증폭 / 치명타 피해 / 공격력 / 스킬 가속 중 선택
