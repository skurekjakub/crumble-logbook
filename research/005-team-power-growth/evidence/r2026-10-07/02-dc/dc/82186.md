2. 노움 연구
유출 내용
* 기본 연구 111~130단
* 총 +33개
* 기본 연구석 18.89G
* 특별 연구석 150개
* 공격력 증폭 +370% 등 연구 효과 수치 공개
* 연구 시간 총 68.9일
실제 업데이트
* 기본 연구 130-2까지 추가
* 특별 연구 22까지 추가
* 연구 항목의 최대 소요 시간이 12시간으로 변경
* 기존 12시간 초과 연구에 대해 1분 가속권 소급 지급
→ 연구 확장 자체는 맞았지만, 유출에서 제시된 세부 수치와 실제 적용 내용에는 차이가 있음.
특히 실제 업데이트에서는 연구 시간 개선 및 소급 보상이 추가됨.
⸻
3. 일일 던전
유출 내용
* 일일 던전 770 → 900단계
* 코인 / 경험치 / 반죽 / 연구석 / 룬결정 던전 모두 +130단계
실제 업데이트
* 900단계 확장 내용은 없음.
* 대신 일일 던전 난이도 완화가 진행됨.
* 경험치 던전: 사서 공격력 및 공격 패턴 하향
* 반죽 던전: 타피오카 개구리·찐만두 들개 공격력 하향
* 연구석 던전: 위험한 우무젤리 체력 및 생성 관련 조정
→ 유출에서는 ‘단계 확장’으로 나왔지만 실제로는 ‘난이도 완화’가 적용됨.
⸻

* 헬리오허니맛 쿠키의 창
* 시간지기 쿠키의 모자
* 퓨어바닐라 쿠키의 망토

* 각 장비의 공격력·방어력·체력 및 서브옵션 수치까지 공개
실제 업데이트
* 이번 공식 업데이트 공지에는 신규 장비 추가 내용이 없음.
→ 유출된 신규 장비 3종은 실제 업데이트 내용에는 포함되지 않음.
⸻
5. 샤르도네맛 쿠키
유출 내용
* SSR / 풀속성 / 지원형
* 신록의 성역
* 치명확률·밀어내기 저항 증가
* 다발 시너지
* 직선 상 적에게 피해
실제 업데이트
* SSR / 풀속성 / 지원형
* 신록의 성역
* 직선 상 아군의 치명확률·밀어내기 저항 증가
* 다발 시너지 제공
* 적에게 피해
→ 거의 그대로 실제 업데이트에 적용됨.
다만 유출에서 나온 기본 공격력 133 / 방어력 60 / 체력 2,790 등의 세부 수치는 공식 업데이트 공지에는 포함되지 않음.
⸻
6. 메인 스테이지
유출 내용
* 328-30 → 364-30
* 그레이프 디바인즈 수도원
* 329~364 챕터
* 9개 지역 순환
실제 업데이트
* 그레이프 디바인즈 수도원 추가
* 메인 스테이지 364-30까지 확장
→ 핵심적인 스테이지 확장은 정확하게 적용됨.
다만 실제 공지에는 329~364, +36챕터, 9개 지역 순환 등의 세부 내용은 적혀 있지 않음.
