## Body

설명하기 전에 일주일넘게 14->15 못간사람이고 아직도 올 15강 못해서 개빡쳤고 11강->10강->9강도 당해봤고 13->15강도 당해본 사람이니 나는 이 결과에 대해 아무생각 없다는것부터 말하겠음
우선 강화 확률 테이블에는 제대로 확률이 기입되어 있음
근데 그건 UI에서 보여줄때 쓰는 테이블이고 실제 강화할때는 안씀
플레이트 강화 확률 처리는 서버에서 하게됨.
즉 게임파일에 제대로 확률이 기입되어있더라도 게임사가 아니면 그거대로 서버에서 돌리는건지 아닌지 알 수 없다는거임.
클라에서 서버로 보내는 정보가 어떤 플레이트인지, 현재 몇강인지, 하락방지여부,박살완화여부
서버가 클라로 보내는건 강화결과, 갱신된 플레이트 정보, 지불한 재료정보, 보상정보임
즉 게임내에서 확률이 정상인이 알 방법은 없긴함
혹시나 안 믿을까봐 어떤 테이블인지 어떤 코드구조인지 아래 적겠음
crumble_apk.zip
└─ split_UnityDataAssetPack.apk
└─ assets/patch_binary_set.resource
└─ PlateUpgradeResults.bytes
이 안에는 확률이 적혀 있는 테이블이 있음.
Crumble.PlateUpgradeRateUI
여기에 몇가지 테이블이랑 칸이 있음
테이블이랑 칸은 아래
_plateUpgradeResultTable   ← 확률 테이블
_greatSuccessRateText      ← 대성공 확률 표시 칸
_successRateText           ← 성공 확률 표시 칸
_maintainRateText          ← 유지 확률 표시 칸
_declineRateText           ← 하락 확률 표시 칸
_destroyRateText           ← 박살 확률 표시 칸
Crumble.PlateUpgradePresenter
├─ HandleOnPlateUpgradeButt()
├─ ProcessUpgradeAsync()
└─ _enhancementApi
Crumble.Apis.EnhancementApi
└─ UpgradePlateAsync(
plateSlotId,
grade,
declinePrevention,
destroyMitigation
)
이 둘에서 강화버튼이랑 서버 요청을 담당함
UpgradePlateRequest — 서버에 보내는 요청
PlateDataId        대상 플레이트
PlateGrade         현재 강화 단계
DeclinePrevention  하락 방지 사용 여부
DestroyMitigation  박살 완화 사용 여부
UpgradePlateResponse — 서버에서 받는 응답
UpgradeResult      강화 결과
Plates             갱신된 플레이트 정보
Payments           지불한 재료
Rewards            보상
아까 서로 주고받는 데이터, 위에서 말 했던거임
다 적지는 않았는데 이정도면 제대로 클뜯했다고 생각함
문제있으면 다른 클뜯게이가 정리 더 해줄거라 믿음
세줄요약
즉 강화는 "조작"할 수 있고 "안"할수도 있다.
근데 어떤 난수생성기를 쓰는건지 모르고 게임사가 모르는 찐빠가 있을수도 있음. 거기까지 모르겠고 알아서 잘 토론해라 난 모르겠다
