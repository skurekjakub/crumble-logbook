지난 공지를 통해 안내해 드렸던 플레이트 강화 시스템 개선이
다가오는 9월 23일(수) 업데이트를 통해 적용될 예정입니다.
많은 분들께서 플레이트 강화 실패 시 발생하는 박살로 큰 피로도를 느끼셨던 점에 깊이 공감하며,
강화 실패에 대한 리스크를 완화하고 보다 안정적인 성장 경험을 제공해 드리기 위해 시스템 개선 및 소급 보상을 적용하고자 합니다.
또한, 지속적인 성장을 위한 최고 단계 확장 관련 변경 사항도 함께 적용될 예정입니다.
상세한 내용과 소급 보상 기준은 아래 내용을 확인해 주시기 바랍니다.
■ 플레이트 강화 시스템 개선
- 플레이트 강화 시도 중 박살 발생 시 강화 단계 감소 폭이 완화됩니다.
- 기존 : 박살 발생 시 10단계까지 하락
- 변경 : 박살 발생 시 현재 강화 단계 기준으로 2단계 하락
■ 박살 복구 기능 신규 추가
- 강화 중 박살이 발생했을 때, 시럽쇳물을 사용하여 박살 이전의 강화 단계로 복구할 수 있는 기능이 추가됩니다.
※ 복구 기능 사용 시, 해당 강화 시도에 소모되었던 초코강 및 시럽쇳물은 반환되지 않습니다.
■ 플레이트 최고 단계 확장 및 세부 수치 안내
- 지속적인 성장을 위해 플레이트 강화 최고 단계가 25단계까지 확장됩니다.
- 확장되는 20~24 단계의 강화 확률은 아래와 같습니다.
ㄴ 20단계 : 대성공 0.1000% / 성공 2.0000% / 유지 44.9000% / 하락 42.0000% / 박살 11.0000%
ㄴ 21단계 : 대성공 0.1000% / 성공 2.0000% / 유지 42.9000% / 하락 43.0000% / 박살 12.0000%
ㄴ 22단계 : 대성공 0.1000% / 성공 2.0000% / 유지 40.9000% / 하락 44.0000% / 박살 13.0000%
ㄴ 23단계 : 대성공 0.1000% / 성공 2.0000% / 유지 38.9000% / 하락 45.0000% / 박살 14.0000%
ㄴ 24단계 : 대성공 0.1000% / 성공 2.0000% / 유지 36.9000% / 하락 46.0000% / 박살 15.0000%
- 최고 강화 단계가 확장됨에 따라 대성공 시 재화 100% 환급 기준이 최고 단계 직전인 24단계 대성공으로 조정됩니다.
- 신규로 추가되는 박살 복구 기능 사용 시 강화 단계에 따라 소모되는 시럽쇳물 수량은 아래와 같습니다.
ㄴ 15단계 : 20개
ㄴ 16단계 : 20개
ㄴ 17단계 : 30개
ㄴ 18단계 : 40개
ㄴ 19단계 : 50개
ㄴ 20단계 : 60개
ㄴ 21단계 : 65개
ㄴ 22단계 : 70개
ㄴ 23단계 : 75개
ㄴ 24단계 : 80개
■ 기존 박살 기록 대상 소급 보상 안내
박살 복구 기능 신규 도입에 따라, 이전에 플레이트 강화 박살을 경험하신 분들을 대상으로 데이터 검증을 거쳐 아래와 같이 소급 보상 및 단계 복구가 진행될 예정입니다.
- 플레이트 단계 복구 대상 :
ㄴ 박살이 발생했던 플레이트의 현재 강화 단계가 박살 당시의 단계보다 낮은 경우, 박살 당시의 단계로 복구됩니다.
- 재화 소급 지급 :
ㄴ 박살 발생 이후 해당 플레이트 강화에 사용된 초코강 및 시럽쇳물이 지급됩니다.
ㄴ 소급 적용 예시)
1. 17단계에서 강화를 시도하다가 박살이 발생해 현재 15단계에 머물러 있는 경우,
해당 플레이트는 17단계로 복구되며, 박살 이후 17단계까지 소모된 재화가 지급됩니다.
2. 17단계에서 강화를 시도하다가 박살이 발생한 후 다시 강화하여 현재 19단계에 머물러 있는 경우,
19단계를 유지하고 17단계 도달까지 소모한 재화가 지급됩니다.
- 소급 보상 지급 일정 : 9월 23일(수) 업데이트 종료 후 우편함 지급
※ 소급 보상은 10월 21일(수) 23:59까지 수령 가능합니다.
현재 많은 분들께서 플레이트 강화 재화 수급에 대해 우려를 표해 주고 계신 점 인지하고 있습니다.
강화 재화 소모 동향과 데이터를 면밀히 모니터링하고 있으며, 이번 강화 시스템 개선 이후에도 추후 업데이트를 통해 다양한 콘텐츠 및 경로에서 강화 재화를 더욱 원활하게 획득하실 수 있도록 수급처를 단계적으로 확장해 나갈 예정입니다.
보내주시는 소중한 의견에 항상 귀 기울이며 더욱 만족스러운 플레이 환경을 제공할 수 있도록 최선을 다하겠습니다.
감사합니다.
