1. 결과창은 15개 초과로 쌓였을 때부터 등장
![[nv-34705-3.jpg]]
해당 템 착용 상황
![[nv-34705-4.jpg]]
목걸이
착용 전(왼) / 착용 후(오)
​
2. 전투력은 같은 템이어도 상황에 따라 달라진다
- 목걸이를 집중 -> 스킬증폭으로 바꾼 상황
- 같은 옵션 검이 약 300k 정도 전투력 상승
- 반대로 특정값을 많이 취하면 전투력 - 현상 발생
​
* 전투력 값은 스텟별 적정 가중치가 존재
​
3. 1번과 2번의 조합
- 15개 이상 템을 뽑아 자동 열기 결과창을 띄우고 템 교체 후 다른 템들도 살펴보기
-- 정리하기 비추
![[nv-34705-5.jpg]]
4. 집중은 명중이 선행되어야 한다
- 미스 X -> 디버프 걸릴 확률 0%
- 적중 -> 기본 스킬 확률 + 저항과 집중 결과값이 가중
-- 집중과 저항의 집중률과 저항확률의 적용 수식은 공식 답변에서 제공하기 어렵다고 답변 수령
![[nv-34705-6.jpg]]
* 추가 질문 참고용
장비 세팅하기
![[nv-34705-7.jpg]]
1. 스테이지 위주
- 명중/집중 위주
- 명중, 집중 두 옵션에 치중되다보니 전투력 가중치로 전투력이 낮게 책정됨으로 대미지 보정 값에 불리
- 높은 명중과 집중으로 보스 리트라이 확률 줄이기
​
* 35퍼 트라이시 유리
![[nv-34705-8.jpg]]
2. 전투 위주
- 아레나부터 크럼블, 토벌전 등 전투에 쓰이는 세팅
- 스테이지 장비보다 골고루 옵션을 챙기니 전투력 상승에 유리
- 명중과 집중을 아예 뺀 극 보스형 PVE 컨텐츠 운영 가능
​
* 55% 트라이시 유리
결론
​
미스면 디버프 적용 확률 0%
- 집중 상관 X
​
장비 전투력은 스텟 평균이 맞도록 설계
그에 따른 전투력 가중치 적용으로 중복값은 전투력 상승 미비, 부족한 스텟 채우는 장비는 전투력 대폭 상승
​
35퍼 트라이 = 명/집중 위주 세팅
55퍼 트라이 = 명/집중 살짝 챙긴 전투용 세팅
75퍼 이상 트라이 = 원하는 옵션 챙기기
