# crumble-logbook

Research tool for the Cookie Run: Crumble Guild Conquest (길드 토벌전) meta, plus its React/Hono rewrite.

**Start every session by reading `HANDOFF.md`.** It holds the current state, the rules the user set, the findings and the ordered next steps.

- Design spec: `docs/superpowers/specs/`. Plans: `docs/superpowers/plans/`.
- Research records: `research/NNN-slug/`. Evidence captures are never edited after capture.
- Rank by damage, never by 배 (damage ÷ power).
- Web access: agent-browser, headed, native Chrome via `AGENT_BROWSER_EXECUTABLE_PATH`. No Playwright.
